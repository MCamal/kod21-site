# Код.21 — гибридная версия

Редакционная типографика, космический фирменный визуал, 13 страниц, тёмная и светлая темы.

## Локальный просмотр

Из папки сайта: `python -m http.server 8765 --bind 127.0.0.1`. Открыть http://127.0.0.1:8765/ . Прямое открытие HTML без сервера не поддерживается: данные загружаются из JSON.

## Редактирование

`content.json` содержит анонсы, программы, контакты, команду, тарифы, FAQ и сведения о встрече. `app.js` — структура страниц и поведение, `hybrid.css` — дизайн. После изменения названий/описаний страниц выполнить `node build.mjs`, чтобы обновить SEO-метаданные в HTML. Адреса страниц без хешей; статическому хостингу достаточно обслуживать index.html из папок.

## Перед публикацией

- Уточнить дату встречи: в ТЗ указано «суббота, 4 октября 2026», но 4 октября — воскресенье. Сейчас показано «Октябрь 2026 · дата уточняется».
- Уточнить число встреч абонемента: ТЗ содержит и один завтрак в месяц, и четыре встречи. Цена сохранена — 2 000 ₽, количество не обещается.
- Добавить реальные портреты и фото площадки. Инициалы и подписи честно обозначают места для будущих фото. Иллюстрация кометы с книгой — сгенерированный фирменный арт, не фото клуба.
- Проверить предоставленные Telegram, телефон, площадку и цены перед запуском.
- Формы валидируют имя/контакт и готовят текст для копирования в Telegram. Сообщения не отправляются автоматически; нет фиктивного состояния «заявка отправлена». Для серверной отправки потребуется настроить обработчик и секреты на сервере.
- Яндекс.Метрика не подключена: не предоставлен ID счётчика. Онлайн-оплаты и личного кабинета нет.
- После выбора домена задать абсолютный URL og:image в shell.html и пересобрать страницы.
